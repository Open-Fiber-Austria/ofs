# Regulatorik im Überblick

## Netz- und Informationssystemsicherheitsgesetz 2026

Das Netz- und Informationssystemsicherheitsgesetz 2026 – NISG2026[^1] stellt umfassende Anforderungen zur Verbesserung und 
Harmonisierung der Informations- und Netzwerksicherheit in den österreichischen Organisationen. Es verpflichtet Leitungsorgane 
direkt zur Erreichung eines angemessenen Sicherheitsniveaus.

Als Leitungsorgane werden natürliche Personen beschrieben, die nach Gesetz, Satzung oder Vertrag zur Führung der Geschäfte 
einer Einrichtung berufen sind. Es sollen jene natürlichen Personen umfasst sein, die auf Geschäftsführungs- bzw. Vorstandsebene 
in den jeweiligen Einrichtungen zuständig sind. Gem. Beilage des Parlaments zum NISG2026 gilt außerdem: „eine eingeschränkte 
Befugnis zur Vertretung nach außen (etwa eine Prokura) etabliert noch kein Leitungsorgan. Folglich ist die Position eines 
„Chief Information Security Officer (CISO)“ für sich genommen noch kein Leitungsorgan. Es ist jedoch denkbar, dass jene 
Person, die die Rolle des CISO in einem Unternehmen einnimmt, auch nach Gesetz, Satzung oder Vertrag zur Führung der Geschäfte berufen ist.“[^2]

[^2]: [https://www.parlament.gv.at/dokument/XXVIII/I/308/fname_1723246.pdf](https://www.parlament.gv.at/dokument/XXVIII/I/308/fname_1723246.pdf)


**Betroffenheit:**

Große und mittlere Unternehmen aus folgenden Sektoren sind betroffen:

| **Hohe Kritikalität (Anhang I)**             | **Sonstige Kritikalität (Anhang II)** |
|----------------------------------------------|---------------------------------------|
| Energie                                      | Post- und Kurierdienste               |
| Verkehr                                      | Abfallbewirtschaftung                 |
| Bankwesen                                    | Chemie                                |
| Finanzmarktinfrastrukturen                   | Lebensmittel                          |
| Gesundheitswesen                             | verarbeitendes/herstellendes Gewerbe  |
| Trinkwasser                                  | Anbieter digitaler Dienste            |
| Abwasser                                     | Forschung                             |
| **Digitale Infrastruktur** *(mit Ausnahmen)* |                                       |
| Verwaltung von IKT-Diensten                  |                                       |
| öffentliche Verwaltung                       |                                       |
| Weltraum                                     |                                       |

Digitale Infrastruktur:

- TLD-Namenregister
- qualifizierte Vertrauensdiensteanbieter
- DNS Diensteanbieter (ausgenommen Betreiber von Root-Nameserver)
- **Anbieter öffentlicher elektronischer Kommunikationsnetze oder elektronischer Kommunikationsdienste**
- Vertrauensdiensteanbieter
- Betreiber von Internet-Knoten
- Anbieter von Cloud-Computing-Diensten
- Anbieter von Rechenzentrumsdiensten
- Betreiber von Content Delivery Networks (CDN)
- Verwendung von Lösungen zur Multi-Faktor-Authentifizierung oder kontinuierlichen Authentifizierung, gesicherte Sprach-, Video- und Textkommunikation sowie gegebenenfalls gesicherte Notfallkommunikationssysteme innerhalb der Einrichtung.
